Installing the APK

Three steps. About a minute.

Step 01

Download

Tap Get the app above. The file (≈6 MB) saves to your Downloads folder — no app store, no account needed.

Step 02

Allow the source

Android blocks unknown apps by default. Open Settings → Security → Install unknown apps, pick your browser, and turn on Allow from this source.

Step 03

Install & open

Reopen the downloaded file, tap Install, then Open. Sign in, and you’re in the square — the shared post is waiting for you.

Only install from the official Agora website. Agora is free, and it stays that way — we don’t need your data, and we never share it with ad networks.
