03 — Install in three steps

From download to square in about a minute.

Step 01

Download

Tap Download APK above. The file saves to your Downloads folder — no app store, no account.

Step 02

Allow the source

Android blocks unknown apps by default. Open Settings → Security → Install unknown apps, pick your browser, and enable Allow from this source.

Step 03

Install & open

Reopen the file, tap Install, then Open. Create your account and step into the square.

Only install from the official Agora website. We re-sign every release and never bundle ad or tracking SDKs — if a file claims to be us from anywhere else, it isn’t.
